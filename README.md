# Experiment 6: Responsive Blog
Blog website using Bootstrap and media queries.

## Run
Open `index.html` (internet needed for Bootstrap). Resize the window to see it adapt.

## Deploy on Netlify (free)
Easy way: go to https://app.netlify.com/drop and drag this folder.

Or from GitHub:
1. Log in at https://app.netlify.com
2. Add new site > Import an existing project > GitHub > choose this repo
3. Leave the build command empty and click **Deploy**
